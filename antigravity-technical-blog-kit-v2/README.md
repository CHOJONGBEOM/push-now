# Antigravity Technical Blog Kit

프로젝트 루트에 `.agents` 폴더를 그대로 복사하세요.

```text
.agents/
├── rules/
│   ├── blog-writing.md
│   └── blog-design.md
└── skills/
    └── technical-blog-writer/
        └── SKILL.md
```

`blog-writing.md`: 문체·구조·기술 설명·사실성 규칙  
`blog-design.md`: Typography·Layout·Spacing·Code·Image·Responsive·Accessibility 규칙  
`SKILL.md`: 프로젝트 탐색 → 사실 추출 → 스토리 구성 → 작성 → 디자인 구조화 → 검수 절차
